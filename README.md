## TextMagic

Windows-приложение-хаб для обработки текста в активном поле ввода по горячим клавишам.

### Что умеет ядро

В `TextBridge` реализованы 4 публичных метода:

1. `GetAllText()`
2. `SetAllText(const std::wstring&)`
3. `GetSelectedText()`
4. `SetSelectedText(const std::wstring&)`

### Источник текста

При запуске скрипта по горячей клавише TextMagic использует:

1. последнее физически введённое слово, если пользователь не перемещал каретку и не менял окно;
2. явно выделенный текст, если сессия последнего слова была сброшена;
3. весь текст — только при включённом соответствующем fallback-режиме.

В терминалах поддерживается преобразование текущего введённого слова.
Пока сессия текущего слова актуальна, TextMagic не копирует историю терминала через `Ctrl+C`.
Если сессия недействительна, используется общий fallback: проверка явно выделенного текста
через буфер обмена, а затем — всего текста, если включён соответствующий режим.

### Плагины без перекомпиляции

Скрипты подхватываются из папки `scripts` рядом с `TextMagic.exe`.
Формат: один файл `*.tmscript` (метаданные + тело PowerShell-скрипта).

Пример:

```ini
name=Uppercase
description=Преобразует текст в верхний регистр
hotkey=Ctrl+Alt+U
enabled=true
---
[Console]::InputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

$inputText = [Console]::In.ReadToEnd()
[Console]::Out.Write($inputText.ToUpperInvariant())
```

Поля:

1. `name` - отображаемое имя в UI.
2. `description` - дополнительное описание.
3. `hotkey` - комбинация `Ctrl/Alt/Shift/Win + Key`.
4. `enabled` - `true/false`, включен ли скрипт.
5. После строки `---` идет тело PowerShell-скрипта.

Для совместимости старый `command=` все еще поддерживается, но больше не обязателен.

### Протокол скрипта

1. TextMagic передает исходный текст в `stdin` (UTF-8).
2. Скрипт возвращает новый текст в `stdout` (UTF-8).
3. Код выхода должен быть `0`.

### UI

Главное окно показывает:

1. список загруженных скриптов;
2. кнопки: `Перезагрузить`, `Открыть папку scripts`;
3. контекстное меню списка (ПКМ): `Добавить`, `Включить/Отключить выбранные`, `Удалить выбранные`, `Импорт ZIP`, `Экспорт ZIP`;
4. добавление скрипта через диалог выбора файла или перетаскивание `.tmscript` в окно;
5. меню `Дополнительно`;
6. окно `О программе` с версией и проверкой обновлений через `UpdateService`;
7. окно `Логи выполнения` (включая ошибки скриптов).
8. строку статуса.

Все сообщения (`ошибки/подтверждения`) показываются через стилизованные окна приложения, а не через системный `MessageBox`.

### Структура `src`

1. `src/app` - входная точка и главное окно.
2. `src/core/scripts` - манифесты и запуск скриптов.
3. `src/core/text` - мост к активному текстовому полю.
4. `src/core/update` - проверка/загрузка обновлений.
5. `src/ui` - отрисовка и tooltip.
6. `src/resources` - `rc`/иконка/версия.
