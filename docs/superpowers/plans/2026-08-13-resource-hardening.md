# Resource Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bound clipboard snapshot memory, reject oversized ZIP imports before extraction, and surface incomplete ZIP rollback.

**Architecture:** Keep policy decisions in small testable helpers. Clipboard byte accounting stays in `ClipboardUtils::Detail`; archive rollback remains in `ArchiveFileTransaction`; ZIP preflight is generated by a focused `ArchiveImportPolicy` module and executed by the existing `ScriptRunner` before extraction.

**Tech Stack:** C++17, Win32 clipboard APIs, PowerShell `System.IO.Compression.ZipArchive`, CMake, CTest, MSVC.

## Global Constraints

- Clipboard snapshot memory-backed formats: at most `64 * 1024 * 1024` bytes total.
- ZIP imports: at most 1024 entries, 64 MiB per file, and 256 MiB total uncompressed file content.
- No third-party dependency, user setting, or custom UI change.
- Preserve existing valid clipboard and ZIP behavior below every boundary.
- Do not stage, revert, or modify unrelated working-tree changes.

```cpp

*total = current + next;

```
